# studio

A small, growing collection of focused tools by [wasiif](https://github.com/wasiif).

**Live →** https://wasiif.github.io/studio/

## What's here

| App | Description |
| --- | --- |
| [POMO](apps/pomo/) | Focus timer with five moods — Study, Deep Work, Exercise, Reading, and Custom — each with its own animated backdrop. |
| [SLATE](apps/slate/) | Task list with natural-language input and a note editor with a pressure-sensitive drawing canvas. |

## Philosophy

Every app in this studio:

- Runs entirely in your browser
- Stores your data locally — nothing is sent anywhere
- Has no accounts, no tracking, no analytics
- Works offline after first load
